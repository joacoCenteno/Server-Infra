💡 Probador Rápido desde el Navegador:

Puedes interactuar con los botones de la derecha o abrir directamente estas URLs en pestañas de tu navegador:

GET /api/tasks (Ver JSON de todas las tareas) GET /api/health (Estado de conexión PostgreSQL)
📋 Tareas Registradas 0
Cargando tareas...
GET /api/tasks Listar todas las tareas (admite ?completed=true|false y ?search=texto)
GET /api/tasks/<id> Obtener el detalle de una tarea específica
POST /api/tasks Crear una nueva tarea (Body: JSON con "title" y opcional "description")
PUT /api/tasks/<id> Editar campos de una tarea existente
PATCH /api/tasks/<id>/complete Terminar una tarea (marcar como completada)
DELETE /api/tasks/<id> Eliminar permanentemente una tarea

Ejemplos directos de cURL para correr en tu consola:

# 1. Listar todas las tareas
curl -X GET http://127.0.0.1:5000/api/tasks

# 2. Crear una nueva tarea
curl -X POST http://127.0.0.1:5000/api/tasks \
  -H "Content-Type: application/json" \
  -d '{"title": "Aprender Flask con Postgres", "description": "Crear modelos y migraciones"}'

# 3. Editar una tarea existente (Ej: ID 1)
curl -X PUT http://127.0.0.1:5000/api/tasks/1 \
  -H "Content-Type: application/json" \
  -d '{"title": "Aprender Flask Avanzado", "description": "Actualizado"}'

# 4. Terminar / Completar una tarea (Ej: ID 1)
curl -X PATCH http://127.0.0.1:5000/api/tasks/1/complete

# 5. Eliminar una tarea (Ej: ID 1)
curl -X DELETE http://127.0.0.1:5000/api/tasks/1

Comandos nativos para Windows PowerShell (Invoke-RestMethod):

# 1. Listar tareas
Invoke-RestMethod -Uri "http://127.0.0.1:5000/api/tasks" -Method Get

# 2. Crear una nueva tarea
Invoke-RestMethod -Uri "http://127.0.0.1:5000/api/tasks" -Method Post -ContentType "application/json" -Body '{"title": "Estudiar PostgreSQL", "description": "Configurar tablas y claves"}'

# 3. Editar una tarea (ID 1)
Invoke-RestMethod -Uri "http://127.0.0.1:5000/api/tasks/1" -Method Put -ContentType "application/json" -Body '{"title": "Estudiar PostgreSQL Avanzado"}'

# 4. Terminar / Completar tarea (ID 1)
Invoke-RestMethod -Uri "http://127.0.0.1:5000/api/tasks/1/complete" -Method Patch

# 5. Eliminar tarea (ID 1)
Invoke-RestMethod -Uri "http://127.0.0.1:5000/api/tasks/1" -Method Delete
